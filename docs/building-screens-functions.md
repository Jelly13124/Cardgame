# Base Building Screens — Function Reference (for Codex concept UI)

**Purpose:** 描述基地四栋楼各自的功能、货币、分级(tier)结构与界面内容,供 Codex
生成**概念 UI**。美术必须守 `docs/project-rules.md §1`(Rick and Morty 风格
Sci-Fi Cartoon Wasteland:粗黑描边、大色块、平涂 cel、废土工业)。

> **状态(2026-07-07 改版):** 本文是**新设计的功能规格**,代码尚未实装(等 Codex 概念
> UI 出来后再改)。相对旧版的变化:**悬赏从黑市移到前哨站、承接免费**;前哨站 tier 重排;
> **删除**牌组编辑、商店折扣。实装时按本文为准。

## 通用框架(四栋共通)

- **解锁 + 升级**:每栋楼 tier 0=锁,最高 T3。解锁与逐级升级在**基地主界面**点楼完成
  (弹确认窗)。**解锁花废料 Scrap,tier 升级花瓶盖 Caps**。功能按 tier 逐级开放。
- **两种货币(核心 Core 已于 2026-07-07 删除)**:🔵 **Caps(瓶盖·钱)** = 黑市购物 + 诊所强化
  + **建筑 tier 升级** + 前哨站永久升级 + 战斗/撤离结算;⚙️ **Scrap(废料·捡破烂)** = 铁匠铺
  拆解/打造 + **建筑解锁** + 战斗掉落。**悬赏承接免费,不花任何货币。**
- **界面形态**:诊所/黑市/前哨站 = **全屏页**(deep 背景 + 服务列表);铁匠铺 =
  **可拖动窗口**(4 tab)。概念图请分别按这两种形态出。
- **难度选择**不在任何楼里:它是**主界面 START 按钮正上方**的独立按钮(点开弹窗选 A0-A5)。
- **共享控件**:每个全屏页顶部有标题 + 该页主货币余额;右上角 ✕ 关闭。

| 楼 | 解锁(Scrap) | 升级 T2/T3(Caps) | 内部服务货币 |
|---|---|---|---|
| 铁匠铺 Forge | 60 | 100 / 180 | Scrap |
| 义体诊所 Clinic | 80 | 120 / 200 | Caps |
| 黑市 Market | 100 | 140 / 240 | Caps |
| 前哨站 Outpost | 70 | 100 / 180 | Caps |

## 1. 铁匠铺 Forge(锻造 · Scrap)

**身份**:废铁熔炉 + 铁砧,回收/打造/改造装备。**界面 = 可拖动窗口,顶部 4 个 tab**。
点基地铁匠铺时,铁匠铺窗 + 角色窗**并排弹出**(装备从角色窗拖进铁匠铺工作台)。

| Tab | Tier | 功能 |
|---|---|---|
| **拆解 Dismantle** | T1 | 把仓库装备拆成 Scrap(按稀有度给量;诅咒件额外 +5) |
| **打造 Craft** | T2 | 花 Scrap 打造指定槽位+品质的新装备进仓库 |
| **重铸 Reforge** | T2 | 重掷一件装备的某条词条(可锁定其余、费用递增) |
| **诅咒 Curse** | T3 | 给装备附加诅咒词条(高风险高回报) |

**概念图要点**:窗口顶 tab 栏(4 个,选中高亮);左侧仓库网格,右侧工作台放一件装备
显示词条行;底部主行动按钮 + Scrap 花费角标。锻炉火光/铁砧作为窗口装饰母题。

## 2. 义体诊所 Clinic(赛博医生 · Caps)

**身份**:霓虹管线 + 培养舱的义体改造铺,永久强化角色属性。**界面 = 全屏页**。

| 区块 | Tier | 功能 |
|---|---|---|
| **属性强化 Attr Perks** | T1 | 5 维属性(力量/体质/智力/幸运/魅力)各可花 Caps 逐级 +1,每项默认封顶 3 级 |
| **生命上限 Max-HP** | T2 | 花 Caps 买 +5 生命上限/级 |
| **等级上限 High Cap** | T3 | 把属性强化封顶从 3 提到 5 |

**概念图要点**:属性强化做成 5 行卡片(属性图标 + 名称 + 等级圆点 ●○○ + 购买按钮带
Caps 角标);培养舱/生命体征屏作为页面装饰。

## 3. 黑市 Market(走私商栈 · Caps)

**身份**:骷髅棚顶的走私摊,卖工具、装备,还能兑换货币。**界面 = 全屏页**。
**(悬赏已移到前哨站 —— 黑市不再有悬赏货架。)**

| 区块 | Tier | 功能 |
|---|---|---|
| **工具货架 Tool Shop** | T1 | 花 Caps 买 3 件随机工具(局内消耗道具) |
| **补货刷新 Refresh** | T1 | 花 Caps 刷新货架 |
| **装备货架 Equip Shop** | T2 | 花 Caps 买装备实例(按稀有度定价) |
| **资源兑换 Resource Convert** | T3 | Caps↔Scrap 双向兑换(约 10% 税) |

**概念图要点**:摊位货架分区陈列(工具瓶罐区 / 装备区 / 兑换台);绿皮外星商人 NPC
作为母题。

## 4. 前哨站 Outpost(指挥中心 · Caps / 悬赏中心)

**身份**:雷达天线 + 装甲舱的指挥站。现在是**悬赏中心 + 永久升级(Caps)**的地方。
**界面 = 全屏页**。

| 区块 | Tier | 功能 |
|---|---|---|
| **悬赏 Bounties** | **T1** | **免费承接**契约(不花任何货币)。每日刷新一批可承接的契约;最多同时**持有 3 张**;承接后跨局持有直到完成,达成即时结算发奖。 |
| **安全格 Safe Cells** | **T2** | 提升死亡时保留的背包"安全格"数量(基础 2 + 升级级数)。 |
| **永久升级 Permanent Upgrades** | **T3** | 花 Caps 逐级的永久强化:**起始金币 ↑ / 背包格数 ↑ / 奖励刷新代币 ↑ / 工具槽 ↑**。 |

**悬赏细节**(概念图要能容纳):
- 上半 = **可承接契约列表**(每日刷新;每张:目标文案 + 奖励 + 「免费承接」按钮;持有满 3
  时按钮置灰"悬赏已满")。
- 下半 = **持有中的契约**(标题 + 实时进度条 + 奖励);完成即消失并发奖。
- 目标类型示例:打出 N 张攻击牌 / 局内赚 N 金币 / 击杀 N 精英 / 击杀 Boss / 成功撤离 /
  升级 N 张卡 / 清杂兵 N 只。奖励:Caps / Scrap / 一件指定品质装备。
- 契约数据在 `run_system/data/bounties/*.json`(承接改免费后,`price` 字段忽略/删除)。

**概念图要点**:契约做成"通缉令/合同卷轴"卡片(免费承接按钮);持有区做成进度条列表;
Caps 永久升级做成多行进度条卡片(名称 + 等级圆点 + Caps 花费);雷达/终端屏作为母题。
这是内容最多的一栋(悬赏列表 + 持有 + 3 项升级),布局要能滚动。

> **注**:主界面左下角原来有个悬赏"持有速览"小板 —— 现在悬赏主界面搬进前哨站,那块小板
> 可保留成只读速览,也可删掉,概念图两种都可以出,项目主定。
