# Base Building Screens — Runtime Function Reference

**Purpose:** 描述基地四栋楼当前运行时的功能、货币、分级(tier)结构与界面内容。
美术必须遵守 `docs/project-rules.md §1`(原创 2D 美漫科幻西部:
清晰深色描边、大色块、平涂 cel、轻量 UI07 废土工业语言)。

> **状态:当前运行时契约。** 四栋建筑使用当前 lightline/UI07 组件；
> 悬赏位于前哨站且
> 免费承接；牌组编辑、商店折扣和旧独立升级页均已移除。

## 通用框架(四栋共通)

- **解锁 + 升级**:每栋楼 tier 0=锁,最高 T3。基地主界面只保留单层悬浮建筑图标；
  进入建筑后点击顶部栏左侧的「升级」,打开共用锚定弹窗。弹窗显示当前→下一 tier、
  新解锁功能、废料消耗与持有量,确认后完成升级。**解锁与 tier 升级统一花废料
  Scrap**；功能按 tier 逐级开放。
- **两种货币**:🔵 **Caps(瓶盖·钱)** = 黑市购物 + 诊所强化
  + 前哨站永久升级 + 战斗/撤离结算;⚙️ **Scrap(废料·捡破烂)** = 铁匠铺
  拆解/打造 + **建筑解锁与 tier 升级** + 战斗掉落。**悬赏承接免费,不花任何货币。**
- **界面形态**:诊所/黑市/前哨站 = **全屏页**(深色背景 + 服务列表);铁匠铺 =
  **可拖动窗口**(4 tab)。两种形态复用同一个升级弹窗；锁定建筑也可进入,但服务区
  会隐藏到解锁后。
- **难度选择**不在任何楼里:它是**主界面 START 按钮正上方**的独立按钮(点开弹窗选 A0-A5)。
- **共享顶部栏**:左侧为升级按钮 + Caps 余额,中间为简易建筑图标 + 名称,右侧为
  ✕ 关闭(lightline `btn_close`,方形原比例,不拉伸)。建筑升级实际使用 Scrap,
  仅在点击升级后的弹窗中显示消耗与持有量。
- **装备悬停 tooltip(全局规则,2026-07-08)**:稀有度·槽位(按稀有度着色)+
  词条行(诅咒红/增益绿);**不显示随机生成名**,仅套装件保留自己的名字 + 套装行。
  实现:`run_system/ui/equip_tooltip.gd` 共享 helper(角色窗/仓库/铁匠铺/黑市共用)。

| 楼 | 解锁(Scrap) | 升级 T2/T3(Scrap) | 内部服务货币 |
|---|---|---|---|
| 铁匠铺 Forge | 60 | 100 / 180 | Scrap |
| 义体诊所 Clinic | 80 | 120 / 200 | Caps |
| 黑市 Market | 100 | 140 / 240 | Caps |
| 前哨站 Outpost | 70 | 100 / 180 | Caps |

## 1. 铁匠铺 Forge(锻造 · Scrap)

**身份**:废铁熔炉 + 铁砧,回收/打造/改造装备。**界面 = 可拖动窗口,顶部 4 个 tab**。
点基地铁匠铺时,铁匠铺窗 + 角色窗**并排弹出**(装备从角色窗拖进铁匠铺工作台)。

| Tab | Tier | 功能 |
|---|---|---|
| **拆解 Dismantle** | T1 | 把基地背包装备拆成 Scrap(按稀有度给量;诅咒件额外 +5);另有**竖排的全部/普通/精良/军官批量拆解项**(带确认弹窗;套装/诅咒件不入批量) |
| **打造 Craft** | T2 | 花 Scrap 打造指定槽位+品质的新装备进基地背包 |
| **重铸 Reforge** | T2 | 重掷一件装备的某条词条(可锁定其余、费用递增) |
| **诅咒 Curse** | T3 | 给装备附加诅咒词条(高风险高回报) |

**运行时要点**:窗口顶 tab 栏(4 个,选中高亮);工作台只接收角色窗基地背包的装备拖拽,
不显示仓库列表。仓库仅负责玩家主动存取装备。批量拆解项竖向排列;锻炉火光/铁砧作为窗口装饰母题。

## 2. 义体诊所 Clinic(赛博医生 · Caps)

**身份**:霓虹管线 + 培养舱的义体改造铺,永久强化角色属性。**界面 = 全屏页**。

| 区块 | Tier | 功能 |
|---|---|---|
| **属性强化 Attr Perks** | T1 | 5 维属性(力量/体质/智力/幸运/魅力)各可花 Caps 逐级 +1,每项默认封顶 3 级 |
| **生命上限 Max-HP** | T2 | 花 Caps 买 +5 生命上限/级 |
| **等级上限 High Cap** | T3 | 把属性强化封顶从 3 提到 5 |

**概念图要点**:属性强化做成 5 行卡片(属性图标 + 名称 + 等级圆点 ●○○ + 紧凑橙色
Caps 价签);价签只显示「瓶盖图标 + 数字」并居中,不重复显示「购买」。培养舱/生命体征屏作为页面装饰。

## 3. 黑市 Market(走私商栈 · Caps)

**身份**:深色工业废墟里的走私商栈,卖工具、装备,还能兑换货币。**界面 = 全屏页**。
**(悬赏已移到前哨站 —— 黑市不再有悬赏货架。)**

**最终画面结构(2026-07-14)**:商人与废料柜台已直接烘焙进黑市背景图,不再运行时叠加
独立 NPC/柜台贴图。左侧约 **456px** 是连续的商人场景；右侧从上到下紧贴排列工具
货架、装备货架和紧凑资源兑换区,避免人物、柜台与室内背景产生拼贴感。

| 区块 | Tier | 功能 |
|---|---|---|
| **工具货架 Tool Shop** | T1 | 花 Caps 买 5 件随机工具(局内消耗道具;可按刷新池扩展) |
| **补货刷新 Refresh** | T1 | 花 Caps 刷新货架 |
| **装备货架 Equip Shop** | T2 | 花 Caps 买装备实例,**5 件 = 每个装备槽位各 1 件**(稀有度按权重 50/35/15 逐槽掷,按稀有度定价 60/140/280) |
| **资源兑换 Resource Convert** | T3 | Caps↔Scrap 双向兑换(约 10% 税) |

**货架卡片规则(2026-07-14 定案)**:工具货架固定陈列 **5 件工具**,每件使用完整的
青铜商品卡框；装备货架固定陈列 **5 件装备**,每件使用完整稀有度商品卡框——普通为
钢灰、精良为蓝色、稀有为紫色。装备卡**不显示生成名**,只显示「稀有度 · 槽位」
(按稀有度着色)。商品按钮使用概念图中的固定宽度暗橄榄价签,居中只显示
「数字 + 瓶盖图标」,不显示「购买」字样；刷新按钮只显示刷新图标 +「刷新」,实际刷新
费用放在悬停说明中；兑换区使用两条紧凑的双向兑换行,按钮明确显示「兑换」。

**专用 UI 素材规则**:工具/装备整卡、货架外框和兑换行均使用本次生成的黑市专用框体,
不再套用共享的通用 section/slot 面板。目标是 1:1 保留概念图中的纵向三段货架、完整
卡框比例和窄缝堆叠节奏；不是用通用组件做近似替代。

## 4. 前哨站 Outpost(指挥中心 · Caps / 悬赏中心)

**身份**:雷达天线 + 装甲舱的指挥站。现在是**悬赏中心 + 永久升级(Caps)**的地方。
**界面 = 全屏页**。

**前哨站不配置 NPC**:左侧完整留给永久升级,右上悬赏、右下安全格。

| 区块 | Tier | 功能 |
|---|---|---|
| **悬赏 Bounties** | **T1** | **免费承接**契约(不花任何货币)。货架在本地日期变化时静默换批,界面不显示刷新倒计时;最多同时**持有 3 张**;承接后跨局持有直到完成,达成即时结算发奖。 |
| **安全格 Safe Cells** | **T2** | 提升死亡时保留的背包"安全格"数量(基础 2 + 升级级数)。 |
| **永久升级 Permanent Upgrades** | **T3** | 花 Caps 逐级的永久强化:**起始金币 ↑ / 背包格数 ↑ / 奖励刷新代币 ↑ / 工具槽 ↑**。 |

**悬赏细节**(概念图要能容纳):
- 上半 = **可承接契约列表**(按日静默轮换;每张:目标文案 + 奖励 + 「免费承接」按钮;持有满 3
  时按钮置灰"悬赏已满")。
- 前哨站**不展示持有中的悬赏列表**;已接悬赏的进度可在战斗/主界面速览或其他轻量入口显示,不占用前哨站主界面。
- 目标类型示例:打出 N 张攻击牌 / 局内赚 N 金币 / 击杀 N 精英 / 击杀 Boss / 成功撤离 /
  升级 N 张卡 / 清杂兵 N 只。奖励:Caps / Scrap / 一件指定品质装备。
- 契约数据在 `run_system/data/bounties/*.json`(承接改免费后,`price` 字段忽略/删除)。

**概念图要点**:契约做成"通缉令/合同卷轴"卡片(免费承接按钮),只展示可接悬赏;
Caps 永久升级做成多行进度条卡片(名称 + 等级圆点 + 紧凑橙色 Caps 价签);价签居中只显示
「瓶盖图标 + 数字」,不重复显示「购买」；安全格做成独立升级卡;
**安全格 + 永久升级占比要大一些**,作为前哨站的主功能区之一,不要挤成侧边小模块。
雷达/终端屏作为母题。布局包含可接悬赏 + 大安全格区 + 大永久升级区,必要时可滚动。

> **注(实装定案)**:主界面左下角的悬赏"持有速览"小板**保留**为只读速览(持有契约 +
> 实时进度,`home_base_scene._add_bounty_board_panel`)；不显示刷新时间或逐行奖励印章。
> 前哨站只展示可承接货架。
