# Base Building Screens — Function Reference (for Codex concept UI)

**Purpose:** 描述基地四栋楼各自的功能、货币、分级(tier)结构与界面内容,供 Codex
生成**概念 UI**。美术必须守 `docs/project-rules.md §1`(Offbeat Adult Sci-Fi Cartoon
Wasteland:粗黑描边、大色块、平涂 cel、废土工业)。

## 通用框架(四栋共通)

- **解锁 + 升级**:每栋楼 tier 0=锁,最高 T3。解锁与逐级升级在**基地主界面**点楼
  完成(弹确认窗,花 **Core**)。费用见下表。楼的**功能按 tier 逐级开放**。
- **三种货币**:🔴 **Core(核心)** = 解锁/升级楼 + 前哨站的永久升级;🔵 **Caps(瓶盖)**
  = 诊所强化 + 黑市购物;⚙️ **Scrap(废料)** = 铁匠铺工艺。
- **界面形态**:诊所/黑市/前哨站 = **全屏页**(deep 背景 + 服务列表);铁匠铺 =
  **可拖动窗口**(4 tab)。概念图请分别按这两种形态出。
- **共享控件**:每个全屏页顶部有标题 + 该页主货币余额;右上角 ✕ 关闭。

| 楼 | 解锁 Core | 升级 Core(T2/T3) | 主货币 |
|---|---|---|---|
| 铁匠铺 Forge | 60 | 100 / 180 | Scrap |
| 义体诊所 Clinic | 80 | 120 / 200 | Caps |
| 黑市 Market | 100 | 140 / 240 | Caps |
| 前哨站 Outpost | 70 | 100 / 180 | Core |

## 1. 铁匠铺 Forge(锻造 · Scrap)

**身份**:废铁熔炉 + 铁砧,回收/打造/改造装备。**界面 = 可拖动窗口,顶部 4 个 tab**。
点基地铁匠铺时,铁匠铺窗 + 角色窗**并排弹出**(装备从角色窗拖进铁匠铺工作台)。

| Tab | Tier | 功能 |
|---|---|---|
| **拆解 Dismantle** | T1 | 把仓库装备拆成 Scrap(按稀有度给量;诅咒件额外 +5) |
| **打造 Craft** | T2 | 花 Scrap 打造指定槽位+品质的新装备进仓库 |
| **重铸 Reforge** | T2 | 重掷一件装备的某条词条(可锁定其余、费用递增) |
| **诅咒 Curse** | T3 | 给装备附加诅咒词条(高风险高回报) |

**概念图要点**:窗口顶 tab 栏(4 个,选中高亮);左侧仓库网格,右侧工作台放一件装备
显示词条行;底部主行动按钮 + Scrap 花费角标。锻炉火光/铁砧作为窗口装饰母题。

## 2. 义体诊所 Clinic(赛博医生 · Caps)

**身份**:霓虹管线 + 培养舱的义体改造铺,永久强化角色属性。**界面 = 全屏页**。

| 区块 | Tier | 功能 |
|---|---|---|
| **属性强化 Attr Perks** | T1 | 5 维属性(力量/体质/智力/幸运/魅力)各可花 Caps 逐级 +1,每项默认封顶 3 级 |
| **生命上限 Max-HP** | T2 | 花 Caps 买 +5 生命上限/级 |
| **等级上限 High Cap** | T3 | 把属性强化封顶从 3 提到 5 |

**概念图要点**:属性强化做成 5 行卡片(属性图标 + 名称 + 等级圆点 ●○○ + 购买按钮带
Caps 角标);培养舱/生命体征屏作为页面装饰。**注意**:当前每行是"图标+名+圆点+右侧购买
按钮"的横条,概念图可美化成义体强化槽的样子。

## 3. 黑市 Market(走私商栈 · Caps)

**身份**:骷髅棚顶的走私摊,卖悬赏契约、工具、装备,还能兑换货币。**界面 = 全屏页**。

| 区块 | Tier | 功能 |
|---|---|---|
| **悬赏契约 Bounty Shelf** | T1 | 每日 3 张契约:1 张免费领 + 2 张 Caps 购买(承接后进基地悬赏板,完成得奖励) |
| **工具货架 Tool Shop** | T1 | 花 Caps 买 3 件随机工具(局内消耗道具) |
| **补货刷新 Refresh** | T1 | 花 Caps 刷新货架 |
| **装备货架 Equip Shop** | T2 | 花 Caps 买装备实例(按稀有度定价) |
| **资源兑换 Resource Convert** | T3 | Core→Caps、Caps→Scrap(约 10% 税) |

**概念图要点**:摊位货架分区陈列(契约卷轴区 / 工具瓶罐区 / 装备区 / 兑换台);契约卡带
目标文案 + 奖励 + 价格 + 承接按钮;绿皮外星商人 NPC 作为母题。这是内容最多的一栋,
布局要能容纳 4-5 个分区(可滚动)。

## 4. 前哨站 Outpost(指挥中心 · Core)

**身份**:雷达天线 + 装甲舱的指挥站,管永久 Core 升级、难度、牌组。**界面 = 全屏页**。

| 区块 | Tier | 功能 |
|---|---|---|
| **Core 永久升级** | T1 | 起始金币↑ / 商店折扣↑ / 背包格↑ / 刷新代币↑ / 工具槽↑(各花 Core 逐级) |
| **难度选择 Difficulty** | T1 | 选下一局的 Ascension 难度(A0-A5,已通关的可选) |
| **安全格 Safe Cells** | T2 | 提升死亡时保留的背包"安全格"数量 |
| **牌组编辑 Deck Editor** | T3 | 每个英雄的起始牌组自定义(≤2 张替换) |

> 注:难度选择在游戏里也做了一份到主界面顶栏的快捷入口(顶栏"难度 A0"按钮),前哨站内
> 的难度区块是完整版。概念图仍按前哨站含难度区块出即可。

**概念图要点**:Core 升级做成多行进度条卡片(名称 + 等级圆点 + Core 花费);难度做成
A0-A5 横向选择器;牌组编辑做成入口按钮。雷达/终端屏作为母题。
