Pre-War Auto-Injector 战前肾上腺素针

curse-trapadrenaline_shot2 optionsacts 1, 2
一支军用自动注射器，玻璃管里晃荡着泛出病态琥珀光的液体。一剂战前作战血清——保证让你出手更狠，此后却会对每一道阴影都心惊肉跳。
  • 扎下去——感受那股灼烧（力量 +1，永久）
  • 一脚碾碎药瓶
  • INJECT → 烈焰顺着手臂炸开，你的肌肉为之轰鸣——你变强了，持久地强。可你的心跳再不肯慢下来，任何响动都吓得你魂飞魄散。
  • CRUSH → 你把注射器碾进泥里。不管它能给什么好处，这价码都太狠了。

Buried Cache 埋藏的暗格

buried_cache2 optionsall acts
一扇锈蚀的舱盖从沙丘里探出，半埋在沙中。旧民兵的标记警告下方封着一座补给库。那把锁看起来快撑不住了。
  • 撬开它，把装备拿走
  • 赌那腐朽的地板，深入下去
  • PRY → 舱盖刺耳地弹开。里头真空封存着一件大崩溃前的装备，静静等着。
  • DIVE_OK → 木板撑住了。在最深处的储物柜里，你找到一件旧世界的稀有遗物，还有一小笔藏起来的钱。
  • DIVE_FAIL → 地板塌了。你摔在扭曲的钢筋上，空着手、漏着冷却液爬了出来。

The Caravan Checkpoint 商队检查站

caravan_checkpoint3 optionsacts 1, 2
油桶和刺网搭成的临时关卡拦住了干涸的河床。两名穿着杂色护甲的卫兵懒洋洋地靠在阴影里，步枪横在膝上，看着你走近。
  • 帮卫兵扶起倒下的油桶，换取通行
  • 靠嘴皮子通关——顺便了结一段旧人情
  • 虚张声势说自己有暗哨，量他们不敢拦
  • HELP → 你把倒下的油桶重新架回刺网上。领头的卫兵哼了一声，扔给你几枚硬币当辛苦费，挥手放你过去。
  • TALK → 原来你认识领头卫兵的表亲。报上几个对的名字后，他不仅放你通行，还顺手帮你了结了一笔旧账，对你有利。
  • BLUFF_OK → 你故意瞟向山脊，仿佛援军就埋伏在那。他们先怂了，放下刺网，甚至退给你过路费以示交好。
  • BLUFF_FAIL → 他们识破了你的虚张声势。第一枪警告打偏，但你还没退回河岸，第二枪就擦中了你。

The Collapsed Overpass 坍塌的高架桥

collapsed_overpass3 optionsacts 2, 3
一座高架公路桥拦腰断在峡谷上，锈蚀的钢筋刺向天空。瓦砾间闪着旧补给箱的微光——可每当风向一变，整块桥板就发出呻吟。
  • 慢慢来、小心翼翼地把残骸捡干净
  • 拦下路过的拾荒队，分成请他们撑住桥板
  • 钻到呻吟的桥板下，去掏最深处的补给
  • PICK → 你花了一下午，撬下那些不会引发坍塌的东西。废料和钱币收获不多，但十根手指都还在。
  • FLAG → 你三言两语就说动了拾荒队。他们用液压顶撑起桥板，你们平分了补给，各自满载而归。
  • CRAWL_OK → 桥板撑住了。你拖出一箱密封的精炼废料和一只鼓囊囊的钱袋，赶在塌落前爬了出来。
  • CRAWL_FAIL → 风向变了。混凝土崩落，压住了你的腿——你扯断受损线路挣脱出来，补给就此永远埋在了下面。

curse-trapcursed_safe2 optionsall acts

  • 撬开它，把瓶盖塞进兜里
  • 走开。会发绿光的东西没一样是白送的。
  • CRACK → 瓶盖落进你手心——一层橙色的锈迹顺着手臂爬上来。一张诅咒钻进了你的行囊。
  • LEAVE → 你退开了。箱子继续嗡鸣，等着更贪心的人。

The Deserter's Charm 逃兵的护符

curse-trapdeserter_charm2 optionsall acts
一枚锈蚀的护符悬在逃兵被晒白的头骨上，仍带着微温。据说它让上一个主人活了下来——代价是让他逢战必逃。
  • 戴上它——保命要紧（回满生命）
  • 让逝者留着它
  • WEAR → 暖意涌进你的伤口，几秒便愈合如初。但一缕冰冷的怯意也随之钻入——你的双手再也按捺不住想逃的冲动。
  • LEAVE → 你把护符留给它的主人。有些交易，光是开口就已经太贵。

The Fortune Shrine 命运神龛

fortune_shrine2 optionsall acts
一座焊废件而成的粗陋祭坛斜倚在尘土里，四周环着供奉的硬币和打空的弹壳。中央摆着一只裂了口的骰盅，向你挑衅。
  • 留下一枚硬币供奉，转身离开
  • 掷那只裂口骰子，赌神龛的窖藏
  • OFFER → 你把一枚硬币丢进尘里，低头致意。这一拜之间，你只觉胜算朝自己偏了几分。
  • ROLL_OK → 骰子掷出福兆。祭坛的暗格塌开，一枚幸运齿轮和一把散币落进你手心。
  • ROLL_FAIL → 两个一点。废件祭坛猛地一晃，一根暗藏的尖刺在你空手缩回时划过手臂。

The Hooded Stranger 兜帽下的陌生人

hooded_stranger3 optionsall acts
将熄的篝火旁坐着一个裹着灰布的身影，脸隐在阴影里。你们之间的一块平石上，扣着一副残破的命运卡。
  • 分享你的口粮和你的故事
  • 请他用卡牌为你卜算未来
  • 切牌，听凭命运给什么就拿什么
  • SHARE → 陌生人静静听着，用药膏替你敷好伤口；讲述之间，你与人相处也多了几分从容。
  • READ → 他发出三张牌，缓缓点头，为你描出命数。你离开时，只觉骰子都会向着你落。
  • CUT_OK → 你翻出『太阳』。陌生人赠你一具精良的拾荒者透镜，随即没入黑暗。
  • CUT_FAIL → 你翻出『高塔』。一阵彻骨的不安抽走你的精气，所幸牌堆里散落几枚硬币，权当安慰。

  • BROWSE → 你在摊位间游荡，低声寒暄几句，离开时识人察色又老练了几分。

Rad Storm 辐射风暴

rad_storm3 optionsacts 2, 3
天空泛起淤青般的绿，呼啸的狂风卷着发光的尘埃扑面而来。你跑不赢它——只能选择如何熬过这阵浪潮。
  • 蜷下身子硬扛过去（失去 4 点生命）
  • 拦下过路的车队求个庇护
  • 冲过辉光，奔向一座地堡
  • HUNKER → 你裹紧自己，隔着围巾呼吸。风暴把你的皮肤刮得生疼，但终究放过了你。
  • CONVOY → 你拼命挥手、巧言相求，换来对方回应。他们把你拽进密封货车，替你包扎，还塞给你些路费。
  • SPRINT_OK → 你穿过最凶的一段，砰地关上地堡舱门。黑暗里，一箱密封的战前废料静静等着——你只觉时运在身。
  • SPRINT_FAIL → 风暴在旷野里逮住了你。你抵达地堡时焦灼欲呕，那股辐射还在肺里灼烧。

Stranded Trader 困在荒野的商人

stranded_trader3 optionsacts 1, 2
一辆商队车死在龟裂的盐碱地上，一只轮子陷进沙里。他从蒙尘的围巾上方眯眼打量你，手始终没离开枪套。
  • 帮他把车挖出来（他付你 +40 瓶盖）
  • 甜言蜜语，从他的货箱里讨件临别礼
  • 用他灌了铅的骰子赌那只保险箱
  • DIG → 铲了几个钟头，车终于猛地松脱。他数了四十枚塞进你掌心，碾着尘雾扬长而去。
  • TALK → 你随和的笑容打动了他。他翻出一枚幸运齿轮，塞进你手里，谢你一路作伴。
  • ROLL_OK → 骰子掷出七点。他嘟囔着，把保险箱里的一捆精炼废料抛给你。
  • ROLL_FAIL → 两个一点。他大笑，拔枪，在你退开前擦伤了你的肩膀。

Torn Coin Pouch 破洞钱袋

curse-traptorn_coin_pouch2 optionsall acts
一个慌张的流浪汉把一只鼓胀的钱袋塞进你手里，没等你拒绝就溜了。缝线开裂、渗着锈迹——硬币已经从你指缝间漏了出来。
  • 收下吧——钱就是钱（+100 瓶盖）
  • 丢下它，转身就走
  • POCKET → 你把钱袋塞好，凭空多了一百。可那道裂口撑不住——你每走一步，就有一两枚硬币漏进身后的尘土。
  • DROP → 你松手让那不祥之物落地。不管它出了什么毛病，现在都不关你的事了。
