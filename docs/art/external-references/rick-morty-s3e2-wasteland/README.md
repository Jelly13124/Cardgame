# S3E2 Nuclear-Wasteland Study Frames

These frames are an internal visual study set from *Rick and Morty* Season 3,
Episode 2, “Rickmancing the Stone.” They were captured from official Adult Swim
public clips:

- [Design Sneak Peek: Wasteland](https://www.adultswim.com/videos/rick-and-morty/design-sneak-peek-wasteland)
- [Hemorrhage Unmasked](https://www.adultswim.com/videos/rick-and-morty/hemorrhage-unmasked)
- [The Blood Dome](https://www.adultswim.com/videos/rick-and-morty/the-blood-dome)
- [Inside: Rickmancing the Stone](https://www.adultswim.com/videos/rick-and-morty/inside-rickmancing-the-stone)

`reference-board.png` is the quickest review surface. The individual frames are
kept beside it so artists and generation prompts can inspect silhouettes,
costume construction, group variety, palette separation, vehicles, and
environment staging at larger size.

## How To Use This Set

- Use frames `04` through `13` and `16` for body type, face acting, clothing
  mass, silhouette, and faction-variety studies.
- Use frames `01` through `03`, `07`, `14`, and `15` for world, vehicle, arena,
  and nuclear-wasteland staging.
- Carry over broad principles only: wobbly dark outlines, flat cel colors,
  rubbery but recognizable anatomy, clear dominant shapes, restrained detail,
  and comedy through posture or expression.
- Keep production designs original. Do not trace or copy any character,
  costume, mask, vehicle, prop, location, composition, crop, logo, or
  franchise-specific feature visible in these frames.
- These files are documentation-only references. Runtime code and exported game
  assets must not depend on them.
